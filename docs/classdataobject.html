◆ copy_parameters_nocb()

void dataobject::copy_parameters_nocb ( int id_n,
const rec_ptr & this_rec,
odeproblem * prob )

Copies parameters from the data set under nocb

Parameters
id_nThe current ID number (zero to nid-1)
from_dataIs the record actually in the data or not
this_rowThe data set record position (rec->pos())
odeproblemThe problem object
  • done_copying, next_copy_row, and last_copy_row are initialized for each id
  • If the record is from the data set, we copy the parameters from that row, then do some bookkeeping to figure out if we are done copying or to get the number of the next row to copy when we're advancing away from a data set record and toward a non-dataset record
  • The next_copy_row comparison against last_copy_row make sure that when we're processing the first inserted record after a data set record, we copy the next data set row just once; this is nocb behavior
