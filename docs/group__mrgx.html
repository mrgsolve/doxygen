Detailed Description

Extra C++ functions provided by mrgsolve. To use these functions, use $PLUGIN mrgx in your model file. Using mrgx will also invoke the Rcpp plugin.

◆ mt_fun()

Rcpp::Function mrgx::mt_fun ( )

An empty R function. This is typically used as a placeholder when declaring an Rcpp::Function object in $GLOBAL. This pattern of declaring in $GLOBAL and (re)defining in $PREAMBLE could be used for efficiency when the function must be called many times.

$PLUGIN mrgx
$ENV
NORM <- function(n, mu, sd) rnorm(n, mu, sd)
$GLOBAL
Rcpp::Function fun = mrgx::mt_fun();
$PREAMBLE
fun = mrgx::get<Rcpp::Function>("NORM");
$MAIN
Rcpp::NumericVector ans = fun(1000, 33, 3);
if(FINAL_ROW) {
mrgx::assign("vec", ans, self);
}
